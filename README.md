# 💰 MeuBolso

**Gerenciador Financeiro Pessoal desenvolvido em Python.**

O MeuBolso é um projeto desenvolvido com o objetivo de organizar receitas e despesas, acompanhar movimentações financeiras e gerar relatórios de gastos.

O projeto utiliza conceitos de programação, manipulação de dados, funções, módulos, persistência em JSON e bibliotecas nativas do Python.

Desenvolvido como projeto prático de aprendizado e evolução em Python, com foco em organização, boas práticas e desenvolvimento de software.

## 🚀 Funcionalidades

- [ ] Cadastro de receitas
- [ ] Cadastro de despesas
- [ ] Listagem de movimentações
- [ ] Consulta de saldo
- [ ] Relatórios financeiros
- [ ] Pesquisa de movimentações
- [ ] Remoção de movimentações
- [ ] Exportação de relatórios

## 🛠️ Tecnologias

- Python 3
- JSON
- Bibliotecas nativas do Python
